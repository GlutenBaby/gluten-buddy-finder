# Gluten Baby

Scan a dish, see its gluten ingredients, and find gluten-free alternatives from the catalog.

Vite + React + TypeScript + Tailwind, wrapped in Capacitor for iOS, with a Supabase backend
(project `yntqzzlbzzhrcrlkzisa`). See `CLAUDE.md` for structure, workflows and deploy commands.

```
npm install
npm run dev     # http://localhost:8080
npm run build
```
